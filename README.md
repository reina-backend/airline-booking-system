
# ✈️ Airline Booking System

### 항공 예약 및 전자항공권 발권 시스템

항공 예약·발권 실무 경험을 바탕으로 제작한 개인 웹 프로젝트입니다.

항공편 검색부터 예약, 부가서비스 선택, 결제, 전자항공권 발행까지
항공 예약의 주요 과정을 하나의 웹 애플리케이션으로 구현했습니다.

---

### 📌 Project Overview

| 항목 | 내용 |
|---|---|
| 프로젝트 유형 | 개인 프로젝트 |
| 개발 분야 | Backend / Web Application |
| 주요 기술 | Java, Spring Boot, JPA, MySQL, Redis |
| 배포 환경 | AWS EC2, Docker Compose, Nginx |
| 프로젝트 상태 | 주요 기능 구현 및 배포 테스트 완료 |

---

### 🎯 Project Goals

- 항공 예약·발권 업무 흐름을 웹 서비스로 구현
- 예약, 승객, 항공권 등 관계형 데이터 구조 설계
- Redis를 활용한 임시 데이터 관리
- Docker 기반 실행 환경 구성 및 AWS 서버 배포
- 실제 예약 과정을 테스트하고 개선
